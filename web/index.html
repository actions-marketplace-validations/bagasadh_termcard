NO TERMINAL NEEDED / 02

Add to GitHub in 4 browser steps

  1. 01

    Open your profile repo

    Go to github.com/username/username (create a new public repo with the exact same name as your GitHub username if you do not have one yet).

  2. 02

    Add termcard.json

    Click Add file then Create new file, name it termcard.json, paste the config from the builder above, and commit.

  3. 03

    Add workflow & markers

    Create .github/workflows/termcard.yml with the YAML from the second tab, then paste the two TERMCARD comment lines into README.md.

  4. 04

    Run the Action once

    Open the Actions tab in your repo, select Update termcard, and click Run workflow. Your SVGs update automatically every day after that.
